# pixel-office

A personal multi-agent dev workspace: hand a task to a team of Claude agents (manager, architect, coder, reviewer, tester, plus debugger and researcher on demand), approve their PRs, and watch them work in a pixel-art office.

Design: [docs/design.md](docs/design.md). What's built and how to use it: [docs/status.md](docs/status.md).

- `apps/control` – the control app: agent runner, safety guard, task pipeline, board, PR reviews.
- `apps/pixel` – Pixel Agents fork (git subtree of github.com/pixel-agents-hq/pixel-agents, MIT). Has its own `npm install`; not an npm workspace.
- `tools/` – office layout and art generators (`build_layouts.py`, `build_art.py`, `apply.sh <layout>`), and the Slack app manifest.

## Run it

    npm install
    npm run office        # task board: http://127.0.0.1:4100
    npm run pixel         # pixel office: http://127.0.0.1:3100 (also shown in the board's Office tab)
    npm test              # control app tests

The control app needs a Claude subscription token in `~/.office/env`, created once with `claude setup-token`:

    CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-…     (chmod 600; the folder chmod 700)

Runtime data (database, task documents, worktrees, knowledge files, graphs) lives in `~/.office/`. Built-in agents and skills are in `apps/control/agents/*.md` and `apps/control/skills/*/SKILL.md`; edits made on the board's Team page are saved in `~/.office/agents` and `~/.office/skills` and override them.

## Keep it running on your Mac

    tools/mac-agent.sh install                # or: install --with-pixel, to keep the pixel office running too
    tools/mac-agent.sh status
    tools/mac-agent.sh uninstall

`install` adds a login item (a launchd agent, `com.pixeloffice.office`). It starts the office when you log in and again if it stops, so Slack from your phone works whenever the Mac is awake. While it runs on power, the Mac doesn't idle-sleep (`caffeinate`); on battery it sleeps as usual. A MacBook with its lid closed sleeps anyway, unless it's on an external display.

- If you start the office by hand (`npm run office`) first, the login item waits until yours stops, then takes over. While the login item's copy runs, `npm run office` just says it's already running: `tools/mac-agent.sh uninstall` stops it.
- Run `install` from your usual terminal: it records that shell's PATH (and `OFFICE_HOME` / `OFFICE_PORT` if you set them), so the office finds node, git, gh and each repo's tools (flutter, uv, …). Run it again after changing your PATH or moving this checkout.
- Log: `~/.office/server.log` (`~/.office/pixel.log` for the pixel office).
- launchd starts `node` itself (`tools/office-service.mjs`), not a shell script: macOS only lets a login item into `~/Documents` when the program it starts has been allowed there. If the log says "Operation not permitted", allow node (`~/.local/opt/node/bin/node`) under System Settings → Privacy & Security → Files and Folders (or Full Disk Access).
- Slack reconnects by itself after Wi-Fi drops and sleep, and when the office starts before the network is up (`server/src/slackLink.ts`).
- In Slack you talk to Fury in plain language: there are no commands (`server/src/fury.ts`). Heroes post under their own names, which needs the `chat:write.customize` scope in `tools/slack-app-manifest.yml` (reinstall the app). More in [docs/status.md](docs/status.md).

## Pixel office

`npm run pixel` (or `./start.sh`) runs Pixel Agents with the workspace `~/.office/pixel`, where the board writes the office's activity, so your residents work at their desks while office agents run. To watch a different project, set `PIXEL_WORKSPACE`; to also see your own Claude sessions, turn on "Watch All Sessions" in its settings.

### Themes

The office ships with two looks. `tools/apply.sh agent-hq` is the classic office; `tools/apply.sh helicarrier` is the
Avengers deck of the S.H.I.E.L.D. Helicarrier: Fury runs the Bridge in the centre as the manager, and a mission walks
clockwise around him through Strange's Sanctum (architect), Stark's Workshop (coder), Hulk's Smash Lab (tester),
Widow's Red Room (debugger), Thor's Hall of Asgard (reviewer), Vision's Archive (researcher) and Spider-Man's Daily
Bugle desk (PR writer). Your own Claude sessions land in the Quinjet Bay as S.H.I.E.L.D. field agents, sub-agents
without a hero are blue holograms of their parent, arrivals step out of a portal and departures turn to dust. Restart
`npm run pixel` after applying a layout; the board's Office tab follows the office's theme on its own.

The art is fan-made pixel work generated by `tools/avengers/build_pack.py` (Pillow, via `uv run --with pillow`) into
`tools/avengers-pack/`, which Pixel Agents loads as an external asset directory. Keep it out of upstream pull requests
and out of the public `pixel-agents` package. A theme is plain layout data (`theme`, `residents[].label`,
`agentPalettes`, `agentArea` in the layout JSON), so a hero swap is one line in `tools/build_layouts.py`.

Pull upstream Pixel Agents changes:

    git subtree pull --prefix apps/pixel pixel-upstream main
