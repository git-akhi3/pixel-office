# pixel-office

A personal multi-agent dev workspace: hand a task to a team of Claude agents (manager, architect, coder, reviewer, tester, plus debugger and researcher on demand), approve the plan and the push, and watch them work in a pixel-art office.

Design: [docs/design.md](docs/design.md). What's built and how to use it: [docs/status.md](docs/status.md).

- `apps/control` – the control app: agent runner, safety guard, task pipeline, board, PR reviews.
- `apps/pixel` – Pixel Agents fork (git subtree of github.com/pixel-agents-hq/pixel-agents, MIT). Has its own `npm install`; not an npm workspace.
- `tools/` – office layout and art generators (`build_layouts.py`, `build_art.py`, `apply.sh <layout>`), and the Slack app manifest.

## Run it

    npm install
    npm run office        # task board: http://127.0.0.1:4100
    npm run pixel         # pixel office: http://127.0.0.1:3100 (also shown in the board's Office tab)
    npm test              # control app tests

The control app needs a Claude subscription token in `~/.office/env`, created once with `claude setup-token`:

    CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-…     (chmod 600; the folder chmod 700)

Runtime data (database, task documents, worktrees, knowledge files, graphs) lives in `~/.office/`. Built-in agents and skills are in `apps/control/agents/*.md` and `apps/control/skills/*/SKILL.md`; edits made on the board's Team page are saved in `~/.office/agents` and `~/.office/skills` and override them.

## Run it in the cloud (always on)

`deploy/setup.sh` turns a fresh Ubuntu 24.04 server into an office that restarts itself (systemd `Restart=always`, starts on boot). Slack connects outbound, so DMing the bot works from anywhere with no public URL; the board stays on 127.0.0.1 and you reach it with `ssh -L 4100:127.0.0.1:4100 office@<server>` then http://127.0.0.1:4100. Register repos by their server paths (clone them under `/srv/repos`). Push the repo first so the script can clone it.

## Pixel office

`npm run pixel` (or `./start.sh`) runs Pixel Agents with the workspace `~/.office/pixel`, where the board writes the office's activity, so your residents work at their desks while office agents run. To watch a different project, set `PIXEL_WORKSPACE`; to also see your own Claude sessions, turn on "Watch All Sessions" in its settings.

### Themes

The office ships with two looks. `tools/apply.sh agent-hq` is the classic office; `tools/apply.sh helicarrier` is the
Avengers deck of the S.H.I.E.L.D. Helicarrier: Fury runs the Bridge in the centre as the manager (Captain America stands
with him), and a mission walks
clockwise around him through Strange's Sanctum (architect), Stark's Workshop (coder, with Loki and the Hulkbuster armour),
Hulk's Smash Lab (tester),
Widow's Red Room (debugger), Thor's Hall of Asgard (reviewer), Vision's Archive (researcher) and Spider-Man's Daily
Bugle desk (PR writer). Your own Claude sessions land in the Quinjet Bay as S.H.I.E.L.D. field agents, sub-agents
without a hero are blue holograms of their parent, arrivals step out of a portal and departures turn to dust. A hero sits
at a laptop only while it works (its label is its name and the task, e.g. "Iron Man (developer) / #12 Add login");
off duty it roams its room and stops to chat with whoever is around. While a mission is in flight the deck goes dark
(night mode: the reactor, mind stone, spell circle, gamma tanks, braziers and the Bridge's walkway lights glow, as do
the heroes and the screens they work at; Settings > Night Mode forces it on or off) and the notification sounds are
short brass stings synthesised in the browser, a two-hit "needs you" and a fanfare when a turn is done. Restart
`npm run pixel` after applying a layout; the board's Office tab follows the office's theme on its own.

The art is fan-made pixel work generated by `tools/avengers/build_pack.py` (Pillow, via `uv run --with pillow`) into
`tools/avengers-pack/`, which Pixel Agents loads as an external asset directory. Keep it out of upstream pull requests
and out of the public `pixel-agents` package. A theme is plain layout data (`theme`, `residents[].label`,
`agentPalettes`, `agentArea` in the layout JSON), so a hero swap is one line in `tools/build_layouts.py`.

Pull upstream Pixel Agents changes:

    git subtree pull --prefix apps/pixel pixel-upstream main
